# 정책자금 마스터 클래스 랜딩페이지

정책자금 강의를 위한 랜딩페이지입니다.

## 배포 원칙

이 레포지토리는 **GitHub Pages**를 통해 배포합니다.

### 배포 방법

1. `main` 브랜치에 코드를 푸시합니다.
2. GitHub Pages가 자동으로 사이트를 배포합니다.

### GitHub Pages 설정

- **Source**: `main` 브랜치, `/ (root)` 디렉토리
- **URL**: `https://<username>.github.io/landing-page/`

## 파일 구조

```
landing-page/
├── index.html    # 메인 HTML 파일
├── styles.css    # 스타일시트
├── script.js     # JavaScript 인터랙션
└── README.md     # 프로젝트 설명
```

## 기술 스택

- HTML5
- CSS3 (반응형 디자인)
- Vanilla JavaScript
- Google Fonts (Noto Sans KR)

## 주요 기능

- 반응형 레이아웃 (모바일/태블릿/데스크톱)
- 부드러운 스크롤 네비게이션
- 아코디언 UI (커리큘럼, FAQ)
- 스크롤 애니메이션
- 숫자 카운트업 효과
